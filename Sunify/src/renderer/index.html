Admin Paneli

Kullanıcı verilerini yönetin ve GitHub Releases için Windows sürümü yayımlayın.

Admin paneline giriş ve sürüm yayımlama adımları
  1. Sunify'da abdulkadirguness72@gmail.com hesabına giriş yapın. Bu Supabase hesabının e-postası doğrulanmış olmalı.
  2. Aşağıdaki şifre, Supabase Dashboard şifresi değil, Sunify hesabında kullandığınız hesap şifresidir.
  3. Admin PIN, Supabase Edge Function Secrets içindeki SUNIFY_ADMIN_PIN değeridir. Bu değer uygulama şifrenizden ayrıdır.
  4. Yayın için önce kod değişikliklerini GitHub deposunun main dalına gönderin. Ardından sürüm numarası (ör. 1.0.1) ve yenilikleri girip Sürümü yayımla düğmesine basın. Windows kurulumu GitHub Actions oluşturur ve Releases'e koyar.

İlk kurulumda Supabase secrets içinde SUNIFY_GITHUB_REPOSITORY, SUNIFY_GITHUB_TOKEN ve SUNIFY_GITHUB_REF tanımlı olmalı; GitHub token'ında Actions yazma ve içerik okuma izni bulunmalı. Değişiklikten sonra sunify-admin Edge Function yeniden dağıtılmalıdır.

Bu, admin e-postasıyla uygulamaya girişte kullandığınız şifredir; Supabase Dashboard şifresi değildir. PIN Supabase projesinin Edge Function Secrets bölümündeki SUNIFY_ADMIN_PIN ile aynı olmalı.

Yeni sürüm yayımla

Windows kurulum dosyasını GitHub Actions oluşturup Releases bölümüne yükler.
